Confidentialité

Ce que Vignoscope enregistre, où, et comment refuser la mesure d’audience.

Votre progression reste sur votre appareil

Les leçons commencées, les réponses, les révisions, le carnet de dégustation et les préférences sont enregistrés dans le stockage local de votre navigateur. Ils ne sont envoyés à aucun serveur. Vous pouvez les exporter ou les remplacer depuis la page Sauvegarder mes données de l’atlas ; effacer les données du site dans votre navigateur les supprime.

Mesure d’audience

Aucune mesure d’audience n’est active pour le moment : aucune statistique de visite n’est envoyée. Le site est prêt à utiliser Plausible Analytics, un outil sans cookie ; cette page sera complétée avant toute activation.

Si elle est activée, la mesure se limitera aux pages vues et à ces événements, sans texte libre ni information personnelle :

  • une page vue à chaque contenu ouvert (page simple ou contenu de l’atlas interactif) ;
  • lesson_start et lesson_complete : début et fin d’une leçon, avec l’identifiant de la leçon ;
  • quiz_start et quiz_complete : première et dernière réponse d’un quiz, avec l’identifiant du quiz et le niveau de lecture ;
  • review_start : début d’une séance de révision, avec le nombre de questions ;
  • search_no_results : une recherche restée sans résultat, sans le texte tapé.

Votre choix sur cet appareil : la mesure d’audience est autorisée.

Le choix est enregistré dans ce navigateur et s’applique à la page suivante. Si votre navigateur envoie le signal Global Privacy Control, aucune mesure n’est faite.

Polices de caractères

L’atlas interactif charge ses polices depuis Google Fonts : votre navigateur contacte alors les serveurs de Google, qui reçoivent votre adresse IP. Les pages simples (fiches, leçons, guides) n’en chargent pas.

Hébergement

Le site est hébergé par GitHub Pages (GitHub, Inc.). Selon sa documentation, GitHub enregistre l’adresse IP des visiteurs d’un site GitHub Pages pour la sécurité du service, que le visiteur ait un compte ou non.

Liens externes et signalements

Les sources citées renvoient vers d’autres sites, qui ont leurs propres règles. Le bouton « Signaler une erreur » ouvre un formulaire public sur GitHub.
